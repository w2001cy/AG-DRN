AG-DRN is an attention-guided deep rectification network that integrates both local perception and global modeling capabilities. The codebase is currently being organized.
![整体框图](https://github.com/user-attachments/assets/0470c94a-8d71-47cd-bd82-7ca0afd9e67c)


Dataset Availability
The datasets used in this study include synthetic fisheye images generated by the proposed DMCM method and publicly available real-world fisheye datasets. Due to dataset size and licensing restrictions, the complete dataset is available upon reasonable request.
